# Security Policy

## Authorized Use Only

ScopeGuard AI is for authorized testing only. Use it only on systems you own, lab systems, internal systems where you have written approval, or bug bounty targets where your testing is explicitly in scope.

Do not use ScopeGuard AI for DoS, brute force, fuzzing, credential attacks, payment abuse, destructive testing, unauthorized access, or attempts to access other users' data.

## Reporting Security Issues

Please open a private security advisory or contact the maintainers directly. Do not publish vulnerabilities in ScopeGuard AI before maintainers have had a chance to respond.

## Sensitive Data Handling

ScopeGuard AI is designed not to store cookies, authorization headers, JWTs, session tokens, passwords, payment data, or full request headers. If you discover a path where sensitive data is persisted, treat it as a security bug.

## Supported Versions

This repository is pre-1.0. Security fixes are applied to the main branch.
